# Artisan Crepes — static website

Pickup-only crepe catering (large batches for parties, weddings, corporate and other events) in Sacramento, CA.
Pure HTML + CSS + ~10 lines of vanilla JS. No build step, no frameworks.

## Design
Implements Design System v1.1 (catering) from the UI Designer: `css/tokens.css` + `css/base.css` are copied verbatim; `css/site.css` adds the nav toggle, gradient card placeholders, page heroes and the about layout. All three are minified and **inlined** into each page's `<style>` by `build.py` (critical-CSS rule). Headings use the system serif fallback (Iowan Old Style / Palatino / Georgia); to add Playfair Display, self-host one latin 600 WOFF2 with `@font-face { font-display: swap }` in site.css.

## Files
- `index.html`, `menu.html`, `about.html`, `order.html` (Netlify form `catering-order`), `thank-you.html`, `404.html`: **generated by `build.py`**. Edit content (contact, menu, copy) in `build.py`, then run `python3 build.py` (Python 3, no deps).
- `css/` (sources), `js/nav.js` (accessible nav toggle + min pickup date, <1 KB)
- `img/logo-header-120.webp`, `img/logo-mark-320.webp` (hero, preloaded LCP, and footer), `img/logo-full-563.webp` (about + social image), `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`
- `netlify.toml`, `robots.txt`, `sitemap.xml`

## Deploy to Netlify
1. Drag this folder onto https://app.netlify.com/drop, or connect a Git repo with publish directory `.` and no build command (pages are pre-built and committed).
2. Netlify detects the `catering-order` form automatically. Submissions appear under **Forms**; turn on email notifications there.
3. Add the custom domain and replace the placeholder domain.
4. Submit `sitemap.xml` in Google Search Console and set up a Google Business Profile as a service-area business (Sacramento) with no public address.
